## Why

`CLAUDE.md` describes the site as having three data series, but four tabs (Treasury,
S&P 500 P/E, Yield Curve, Treasury Spreads) plus a shared USREC recession-shading
dataset are live, and the changelog is missing the spreads and USREC additions. The
data-flow description also claims the GitHub Actions workflow commits fetched data
back to `main`, which it does not — it only deploys `data/` → `site/data/` to
`gh-pages`, so `main`'s `data/*.json` can silently lag what's actually published. The
quarterly EPS-regeneration snippet lives inline in `CLAUDE.md` as a heredoc instead of
a runnable script. None of this is a design decision to make — it's fixing drift
between the doc and the running system, per S0 of the cross-session plan in
`~/Obsidian/Investing/Finance and Economic Data Website/Session Plan.md`.

## What Changes

- Correct `CLAUDE.md`'s series count and data-flow description; document that `main`'s
  `data/*.json` is not kept current by the workflow.
- Add `scripts/fetch_spreads.py` and `scripts/fetch_usrec.py` to the Key Files table;
  add the spreads and USREC changelog entries (both shipped 2026-05-31, undocumented
  until now).
- Move the quarterly EPS-regeneration heredoc out of `CLAUDE.md` into
  `scripts/build_earnings_overrides.py`, a runnable script with the same logic.
- Add a Chart Conventions section (established conventions plus the three adopted
  2026-09-12, per the Session Plan decisions table) and a Licence Notes section
  (FRED public-domain baseline vs. provider-copyrighted series; Shiller/Yale; S&P
  Global EPS workbook) to `CLAUDE.md`.
- Add a pointer at the top of `CLAUDE.md` to the Obsidian planning folder (`What I
  Want.md`, `Session Plan.md`, latest `HANDOFF`), so a fresh session finds the
  cross-session plan this repo's docs don't carry.
- Document the known gap that `data/earnings_overrides.json` has run on estimated
  earnings since 2026-03-08 (still true after this change — fixing it needs a fresh
  S&P Global download, which isn't fetchable programmatically).

This is documentation and script-relocation only. No fetch script's output, the
GitHub Actions workflow, or `site/index.html` changes.

## Impact

- **Affected**: `CLAUDE.md` (edited), `scripts/build_earnings_overrides.py` (new).
- **Not affected**: no fetch script, `data/*.json`, `.github/workflows/update-data.yml`,
  or `site/index.html` changes. `data/earnings_overrides.json` is not regenerated by
  this change — running the new script against the current (stale) xlsx would only
  reproduce the same estimated figures with a new `last_updated` stamp, which would be
  misleading.
- **Rollback**: revert the `CLAUDE.md` commit and delete `scripts/build_earnings_overrides.py`;
  nothing else depends on either.
